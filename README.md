# Asset Beta Estimator (Archive / Experimental)

> ⚠️ **Status do Projeto:** Arquivado / Prova de Conceito (PoC). 
> Este repositório contém estudos iniciais para cálculo de Beta de ativos usando Python. 

## 📌 Sobre o Projeto
Estudo exploratório desenvolvido para calcular o coeficiente Beta de ativos em relação ao índice de referência (ex: IBOV/S&P500) utilizando regressão linear.

## ⚙️ Tecnologias Utilizadas
* Python 3.x
* Pandas / NumPy
* Statsmodels / YFinance

## 📝 Aprendizados e Próximos Passos
* Implementação inicial da relação de volatilidade e covariância dos retornos.
